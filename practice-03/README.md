## Организация кода

- `task-service.js` — содержит функции для работы с задачами: создание, поиск, изменение статуса, удаление и вычисление статистики.
- `task-selectors.js` — содержит функцию `getVisibleTasks()`, которая фильтрует задачи по `all`, `pending` и `completed`.
- `task-view.js` — отвечает за создание карточек задач и их отображение в DOM. Здесь также находятся функции для отображения сводки и пустого состояния.
- `main.js` — связывает остальные модули, хранит текущее состояние приложения и обрабатывает события кликов по задачам и фильтрам.

Полный список задач хранится в переменной `currentTasks`, а выбранный фильтр — в `currentFilter` в `main.js`.

События обрабатываются через делегирование: обработчики `handleTaskListClick` и `handleFilterClick` установлены на контейнеры списка задач и фильтров.

Сводка вычисляется с помощью `getTaskStats()` из `task-service.js`, а отображается через `renderSummary()` из `task-view.js`.

## Отладка и клавиатура

Для отладки обработки нажатия на кнопку карточки была установлена точка останова на строке:

```text
const id = Number(card.dataset.taskId);
```

При проверке карточки с `id=4` были получены следующие значения:

- card.dataset.taskId — "4", тип string;
- после преобразования Number(card.dataset.taskId) — 4, тип number;
- action — "toggle";
- найденная задача имела id: 4, completed: false, priority: "high", название «Подготовить модель задач»;
- результат setTaskCompleted(...) имел ok: true;
- после выполнения renderApp() состояние карточки на странице изменилось на выполненное.

`event.currentTarget` при обработке клика указывает на контейнер списка `#task-list`. `event.target` зависит от конкретного элемента, по которому выполнен клик: им может быть сама кнопка или вложенный элемент кнопки. Это подтверждает использование делегирования событий через обработчик списка.

Также была проверена обработка некорректных идентификаторов. При значении `data-task-id="4abc"` преобразование через `Number()` даёт `NaN`, поэтому появляется сообщение «Некорректный id задачи». При значении `data-task-id="777"` число является корректным, но такой задачи нет в текущем наборе, поэтому появляется сообщение «Задача с таким id не найдена». В обоих случаях данные приложения не изменяются.

Клавиатурное управление реализовано для кнопок приложения. Кнопки доступны через `Tab` и могут активироваться клавишами `Enter` и `Space`. После изменения статуса выполняется повторная отрисовка списка, после чего фокус восстанавливается на соответствующей кнопке задачи. После удаления задачи, если прежняя кнопка больше не существует, фокус переводится на кнопку текущего фильтра.

## Вывод

В ходе выполнения практической работы были реализованы и проверены обработчики событий, фильтрация, изменение статуса и удаление задач, а также повторная отрисовка списка. Были исправлены ошибки, связанные с преобразованием `data-task-id`, обработкой неизвестных и некорректных идентификаторов и делегированием событий.

В ходе отладки было установлено, что `dataset.taskId` возвращает строку, поэтому перед поиском задачи значение необходимо преобразовать в число. Для некорректного значения `4abc` приложение выводит сообщение «Некорректный id задачи», а для неизвестного числового id `777` — «Задача с таким id не найдена».

Также было проверено различие между изменением данных и изменением DOM. Состояние задач изменяется через функции сервиса, которые возвращают обновлённый массив задач. После изменения данных вызывается `renderApp()`, которая заново формирует DOM на основе текущего состояния. Таким образом, данные приложения являются источником состояния, а DOM отображает это состояние пользователю.
